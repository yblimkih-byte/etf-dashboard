# 새 탭 추가 방법

탭 1개 = **서버 핸들러 1개(Api.gs)** + **클라이언트 탭 정의 1개(Tabs.html)**. 두 곳만 수정하면 되고, 컨트롤(기준일·기간·운용사·연도·필터)과 차트·표 헬퍼는 공용.

## 1. 서버: Api.gs 에 핸들러 추가

```js
// ACTIONS 에 등록
const ACTIONS = { ..., myTab: apiMyTab_ };

/** 예: 국내/해외별 NAV 추이 */
function apiMyTab_(p) {
  const months = aggMarket_();                 // 월별 시장 집계 [{ym,date,nav,n,k,s,q}]
  const date = p.date || defaultDate_(months); // 기준일 미지정 시 전월말
  const ctx = ctx_();                          // 마스터·범례 (groupOf_ 에 필요)
  const recs = snapshot_(date);                // 기준일 스냅샷 [{code,name,mgr,nav,trdval,ytd,mtd}]
  const byDom = sumBy_(recs, r => groupOf_(r, ctx).dom);   // {국내: nav, 해외: nav}
  return { date: date, byDom: byDom };         // JSON 직렬화 가능한 객체만 반환
}
```

자주 쓰는 서버 헬퍼

| 함수 | 반환 |
|---|---|
| `aggMarket_()` | 월별 시장 집계 (agg_시장월별) |
| `aggRows_(CFG.SHEET.AGG_MGR 등)` | 집계 시트 원본 행 |
| `snapshot_(date)` | 특정일 ETF 레코드(일별 우선, 없으면 월말). 종목 단위가 필요할 때만 사용(느림) |
| `snapRows_(date)` | 특정일 요약 행 `[{mgr, top, f2, dom, nav, n}]` — agg_일별요약/agg_월말요약에서 읽으므로 빠름. 운용사·유형 단위 집계는 이것을 사용 |
| `sumBy_(rows, fn)` / `cntBy_(rows, fn)` | 요약 행을 키 함수로 합산(NAV / 종목수) |
| `readDailyBlock_(date)` | 일별 블록만 (없으면 null) |
| `refDates_(date, months)` | `{pm: 전월말, py: 전년말}` |
| `groupOf_(rec, ctx)` | `{short: 운용사약식, top: 상위구분, f1, f2, dom, neu}` |
| `sumBy_(recs, keyFn)` | 키별 NAV 합계 |
| `chg_(cur, base)` | `{amt, pct}` |

## 2. 클라이언트: Tabs.html 에 탭 정의 추가

```js
App.registerTab({
  id: 'myTab',                 // 고유키 (URL #myTab)
  label: '국내/해외',            // 탭 이름
  controls: ['date'],          // 'date' | 'range'(from/to) | 'year' | 'mgr' | 'filter' 중 필요한 것. 서버 응답은 api() 에서 자동 캐시(데이터 변경 시 무효화)
  action: 'myTab',             // Api.gs ACTIONS 키
  params: s => ({ date: s.date }),   // s = App.state {date, from, to, mgr, filter, year}
  render(d, root, A) {
    const s1 = A.section(root, '국내/해외별 NAV', `기준일 ${d.date}`);
    const keys = Object.keys(d.byDom);
    A.bar(A.canvas(s1), keys, [{ label: 'NAV', data: keys.map(k => d.byDom[k]), color: '#17171c' }], { noLegend: true });
    A.div(s1, '', A.table(keys.map(k => ({ k, v: d.byDom[k] })), [
      { h: '구분', k: 'k', l: 1 }, { h: 'NAV(억원)', f: r => A.eok(r.v) }
    ]));
  }
});
```

클라이언트 헬퍼 (`A` = App)

| 헬퍼 | 용도 |
|---|---|
| `A.section(root, 제목, 부제)` / `A.div(parent, class, html)` | 레이아웃 |
| `A.canvas(parent, 'short'|'tall')` | 차트 캔버스 (높이 240/320/460px) |
| `A.bar(canvas, labels, datasets, opts)` | 막대. `datasets[{label,data,color|colors,stack}]`, `opts: {horizontal, stacked, pctAxis, countAxis, noLegend, fmt, intTicks, padTop, padRight, barPct, catPct, xTickOnly(i,label), labels}`. `labels: {mode:'end'|'inside'|'total'|'names'|'connect'|'right'|'area', fmt, shortFmt, only(i), force, size}` (names=첫 행 위 구간 이름, connect=2행 점선+증감, right=마지막 막대 오른쪽 이름, area=누적 영역 값) 또는 `{list:[…]}` 로 값 레이블 표시 |
| `A.chips(parent, keys, {hint, reset, colorFn, labelFn, onSelect(sel)})` | 운용사 선택 칩(고유색 견본 포함, `reset:true` 면 '초기화' 칩 추가). `A.highlightRows(host, sel)` = 행 강조, `A.filterRows(host, sel)` = 선택 행만 표시(`data-top` 속성 필요). Tabs.html `mgrChips(A, parent, {chart, rowsTop, hosts, filterHosts, reset})` 로 묶어서 사용 |
| `A.race(parent, frames, {n, step, start})` | DOM 기반 bar chart race. `frames: [{ym, rows:[{rank, code, name, top, nav}]}]` |
| `dlabel(d)` | 기준일 표기(지난 달은 `연-월`, 당월은 날짜) |
| `A.line(canvas, labels, datasets, opts)` | 꺾은선/누적 영역. `opts: {pctAxis, unit, fmt, area, max, yWidth, hideX, alignBars(막대와 X 정렬), xTickFmt, padRight, legendPos, labels}` |
| `A.table(rows, cols, {total})` | 표. `cols[{h:헤더, k:필드 또는 f:r=>값, l:좌측정렬, cls:r=>클래스}]` |
| `A.eok(v)` `A.jo(v)` `A.pct(v)` `A.signed(v)` `A.num(v)` | 숫자 포맷 (억원·조·%·부호) |
| `A.color(top)` `A.sw(top)` | 상위 운용사 고유색 / 색 견본 span |
| `A.meta` | `{dates, months, defaultDate, top5, colors, typeOrder, mgrs}` |
| `A.onUnload(fn)` | 탭 전환 시 정리(타이머 등) |
| `tc(type)` | 유형별 색 (Tabs.html 상단 TYPE_COLORS) |

## 3. 새 원천 데이터가 필요한 경우

1. `Config.gs` `SHEET` 에 시트명 추가, `Setup.gs setupSheets()` 에 헤더 추가
2. `Load.gs loadDaily()` 의 `if (loaded) {...}` 블록에 적재 함수 호출 추가 (실패해도 본 적재가 멈추지 않도록 try/catch)
3. 월별 집계가 필요하면 `Aggregate.gs rebuildAggregates_()` 에 집계 추가 → 새 `agg_*` 시트
4. 위 1·2 절차로 탭 연결

## 4. 배포 반영

코드 저장 후 **배포 > 배포 관리 > (기존 배포) 편집 > 버전: 새 버전 > 배포**. 같은 URL에 반영됨. 미리 확인은 "테스트 배포" URL(`/dev`) 사용.

## 5. 새 컨트롤이 필요한 경우

`App.html renderControls()` 에 `if (c === '이름') {...}` 분기 추가 → `App.state` 에 값 저장 후 `this.load()` 호출. 기존 `'mgr'` 분기가 가장 단순한 예.
